# 💳 AQSHA — Личный финансовый планировщик для Казахстана

Премиальный, строгий и эстетичный личный финансовый дашборд в тёплой журнальной стилистике AQSHA («Месяц — одной цифрой»).
Разработан специально под финансовые реалии Казахстана: тенге (₸), карты Kaspi Gold, Банк ЦентрКредит (#IronCard, #картакарта), Halyk, Forte, Jusan, депозиты BCC («Моя цель» и «Чемпион») с капитализацией, подписки и цели.

---

## ✨ Возможности

1. **Динамический 3D-стек банковских карт:**
   - Добавление любых собственных карт банков Казахстана (Kaspi, BCC, Halyk, Forte, Jusan, кастомные) с живым предпросмотром карты при вводе.
   - Маскирование номеров `•••• 7183`, чип EMV, значок бесконтактной оплаты, переключение кликом или стрелками.
2. **Депозиты BCC и Накопления:**
   - Вклады «Моя цель» (18.06% ГЭСВ) и «Чемпион» (15.17% ГЭСВ).
   - Действие **«💰 Зачислить %»** с автоматическим расчётом дохода за месяц.
3. **Единый холст без разрозненных вкладок:**
   - Лента операций по дням с точками-маркерами, фильтрами и поиском.
   - Календарь обязательных платежей на 7 и 30 дней с кнопкой проведения в 1 клик `✓`.
   - Цели накоплений с привязкой счетов.
   - Круговая диаграмма аналитики Canvas и норма сбережений (Savings Rate).
4. **Резервное копирование и экспорт:**
   - Экспорт базы в JSON и импорт.
   - Экспорт всех операций в CSV (для Excel / Google Таблиц).
   - Быстрый старт: кнопка «Очистить данные» для ведения своего чистого бюджета с нуля.
5. **100% Offline & PWA:**
   - Приложение полностью автономно, сохраняет данные в `localStorage` и готово к установке как приложение на телефон или компьютер.

## 🌐 Как опубликовать сайт (Деплой)

### Вариант 1: GitHub Pages (Бесплатно за 1 минуту)
1. Создайте репозиторий на GitHub.
2. Запушьте файлы в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "AQSHA Budget Planner Initial Release"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/aqsha-budget.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages** и выберите ветку `main` / root.
4. Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/aqsha-budget/`.

### Вариант 2: Vercel / Netlify
Просто перетащите папку `aqsha-budget-planner` в интерфейс [vercel.com](https://vercel.com) или [netlify.com](https://netlify.com) — сайт развернётся за 10 секунд!
