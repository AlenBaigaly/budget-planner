# 💳 Budget Planner — Личный финансовый дашборд для Казахстана

Строгий, минималистичный и функциональный планировщик личного бюджета, разработанный специально под финансовые реалии Казахстана (тенге ₸, депозиты BCC «Моя цель» и «Чемпион», подписки и регулярные платежи).

---

## 🎨 Дизайн и интерфейс

- **Без SaaS-шаблонов и псевдопикселей**: чистый, строгий тёмный интерфейс (`#0b0d13` и `#131620`) для личного ежедневного использования.
- **Типографика**:
  - Текстовый интерфейс: **Manrope** — чёткий, аккуратный и человечный.
  - Все денежные суммы, проценты, даты и ставки: **JetBrains Mono** с моноширинными табулярными цифрами (`tabular-nums`) — цифры стоят ровно, заметно и никогда не «прыгают».
- **Геометрия**: почти прямоугольные карточки с выверенным радиусом скругления **6–8px** без мыльного свечения и 16px «пузырей».
- **Цветовые акценты**:
  - Тёплый янтарный/золотой (`#f59e0b`) — для накоплений, вкладов BCC и целей.
  - Сдержанный зелёный (`#10b981`) — для доходов и подтверждённых поступлений.
  - Ровный красный (`#ef4444`) — для расходов и предупреждений о лимитах.
- **Информационная плотность**: вместо огромных пустых блоков — компактная 4-колоночная верхняя сводка (Доходы, Расходы, Чистый остаток, Общий капитал), лента ближайших платежей и быстрые действия.
- **Мобильная навигация (5 пунктов)**: на смартфонах нижнее меню не перегружено — ровно 5 кнопок:
  1. `📊 Главная`
  2. `🧾 Операции`
  3. `💳 Счета`
  4. `⚖️ Бюджет`
  5. `☰ Ещё` ➔ выезжающая панель с разделами: *Депозиты BCC*, *Цели*, *Регулярные*, *Календарь*, *Аналитика*, *Журнал*, *Настройки*.
- **Полноценные пустые состояния (Empty States)**: вместо пустых прямоугольников понятные заглушки с кнопками быстрого создания счета или цели.

## ⚙️ Новые функции

1. **Регулярные операции**:
   - Учёт зарплаты, стипендии, аренды квартиры, коммуналки и подписок (Яндекс Плюс, Spotify, Netflix).
   - Задаётся число месяца (например, 5-е или 10-е число), периодичность и счёт.
   - Кнопка «✓» для мгновенного проведения платежа при фактической оплате.
2. **Статусы операций (Подтверждена / Запланирована)**:
   - Операции могут быть `confirmed` (фактически проведённые, влияющие на реальный остаток) или `planned` (будущие).
   - Запланированные операции имеют статус-бейдж и кнопку быстрого подтверждения в 1 клик.
3. **Календарь будущих платежей**:
   - Автоматический расчёт обязательной суммы расходов: **на ближайшие 7 дней** и **на 30 дней**.
   - Хронологическая лента предстоящих регулярных списаний и запланированных трат.
4. **Цели накоплений с привязкой к нескольким счетам**:
   - Теперь к одной цели можно привязать сразу несколько счетов (например, Kaspi Gold + BCC «Моя цель» + Наличные). Прогресс автоматически суммирует остатки всех выбранных счетов.
5. **Депозиты BCC («Моя цель» и «Чемпион»)**:
   - Отдельная карточка вклада с контролем условий (запрет снятия для «Моей цели», неснижаемый остаток 1 000 ₸ для «Чемпиона»).
   - **Действие «💰 Зачислить проценты»**: так как приложение не подключается напрямую к банковскому API, по нажатию рассчитывается прогнозная сумма вознаграждения за месяц с возможностью скорректировать её и в 1 клик зачислить доход на депозит.
   - Помесячный график капитализации и прогноз на конец срока.
6. **Резервное копирование без Firebase**:
   - Быстрый бэкап в JSON доступен прямо в шапке сайта (`💾 Бэкап`) и в настройках.
   - Импорт и экспорт базы данных в 1 клик.
7. **Подтверждение перед удалением и Журнал действий (Audit Log)**:
   - Защита от случайных кликов: модальное окно подтверждения перед удалением счетов, целей или операций.
   - Раздел «Журнал действий», где сохраняется хроника событий (добавление операций, начисление процентов, смена настроек).

## Firebase: безопасная настройка

Перед включением Google-входа добавьте в Firebase Authentication разрешённые домены сайта: адрес GitHub Pages и `localhost` для разработки. В Firestore не оставляйте тестовые открытые правила. Для этого приложения подойдут правила, при которых пользователь видит и изменяет только собственные данные:

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/budget_app/state {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

После первой авторизации приложение создаёт первоначальную резервную копию локальных данных. На другом устройстве актуальная облачная копия применяется локально без обратной записи в Firestore.
